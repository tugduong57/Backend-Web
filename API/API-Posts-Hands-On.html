BƯỚC 1

Tạo API Routes

Mở file: routes/api.php

Thêm route cho API posts (thay thế nội dung hiện tại hoặc thêm vào):

<?php

use Illuminate\Http\Request;
use Illuminate\Support\Facades\Route;
use App\Http\Controllers\Api\PostController;

// Routes công khai - không cần xác thực
Route::apiResource('posts', PostController::class);

// Hoặc chi tiết hơn:
Route::get('/posts', [PostController::class, 'index']);
Route::post('/posts', [PostController::class, 'store']);
Route::get('/posts/{id}', [PostController::class, 'show']);
Route::put('/posts/{id}', [PostController::class, 'update']);
Route::delete('/posts/{id}', [PostController::class, 'destroy']);
✅ Lý giải:
  • apiResource('posts', PostController::class) tạo 5 routes tự động
  • Hoặc có thể khai báo từng route riêng lẻ (phần chi tiết)

Viết Method index() - Lấy Danh Sách

Mở file app/Http/Controllers/Api/PostController.php và viết:

<?php

namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use App\Models\Post;
use Illuminate\Http\Request;
use Illuminate\Http\Response;

class PostController extends Controller
{
    /**
     * GET /api/posts
     * Lấy danh sách tất cả posts
     */
    public function index()
    {
        // Lấy tất cả posts từ database
        $posts = Post::all();
        
        // Trả về JSON response
        return response()->json([
            'success' => true,
            'data' => $posts,
            'message' => 'Danh sách posts'
        ], Response::HTTP_OK);
    }
}
✅ Giải thích:
  • Post::all() lấy tất cả records từ bảng posts
  • response()->json() trả về JSON
  • Response::HTTP_OK là status code 200

Viết Method show() - Chi Tiết Post

Thêm method show() vào PostController:

/**
 * GET /api/posts/{id}
 * Lấy chi tiết một post
 */
public function show($id)
{
    // Tìm post theo ID
    $post = Post::findOrFail($id);
    
    // Trả về JSON response
    return response()->json([
        'success' => true,
        'data' => $post,
        'message' => 'Chi tiết post'
    ], Response::HTTP_OK);
}
💡 Lý giải:
  • findOrFail($id) tìm post theo ID hoặc throw 404
  • Nếu không tìm thấy → tự động trả về 404 error

Viết Method store() - Tạo Post

Thêm method store() vào PostController:

/**
 * POST /api/posts
 * Tạo post mới
 */
public function store(Request $request)
{
    // Validate dữ liệu
    $validated = $request->validate([
        'title' => 'required|string|max:255',
        'content' => 'required|string'
    ]);
    
    // Tạo post mới
    $post = Post::create($validated);
    
    // Trả về JSON response
    return response()->json([
        'success' => true,
        'data' => $post,
        'message' => 'Tạo post thành công'
    ], Response::HTTP_CREATED);
}

BƯỚC 3

Viết Method update() & destroy()

Method update() - Cập nhật Post:

/**
 * PUT /api/posts/{id}
 * Cập nhật post
 */
public function update(Request $request, $id)
{
    $post = Post::findOrFail($id);
    
    $validated = $request->validate([
        'title' => 'sometimes|required|string|max:255',
        'content' => 'sometimes|required|string'
    ]);
    
    $post->update($validated);
    
    return response()->json([
        'success' => true,
        'data' => $post,
        'message' => 'Cập nhật post thành công'
    ], Response::HTTP_OK);
}

Method destroy() - Xóa Post:

/**
 * DELETE /api/posts/{id}
 * Xóa post
 */
public function destroy($id)
{
    $post = Post::findOrFail($id);
    $post->delete();
    
    return response()->json([
        'success' => true,
        'message' => 'Xóa post thành công'
    ], Response::HTTP_NO_CONTENT);
}
💡 Lý giải: sometimes trong validation cho phép field tùy chọn
BƯỚC 4

Tạo API Resource (Tùy Chọn)

API Resource giúp format response một cách nhất quán và chuyên nghiệp.

Tạo Resource:

php artisan make:resource PostResource

File được tạo:

app/Http/Resources/PostResource.php

Nội dung:

<?php

namespace App\Http\Resources;

use Illuminate\Http\Request;
use Illuminate\Http\Resources\Json\JsonResource;

class PostResource extends JsonResource
{
    public function toArray(Request $request): array
    {
        return [
            'id' => $this->id,
            'title' => $this->title,
            'content' => $this->content,
            'created_at' => $this->created_at->format('Y-m-d H:i:s'),
            'updated_at' => $this->updated_at->format('Y-m-d H:i:s'),
        ];
    }
}
✅ Lợi ích:
  • Format date/time theo mong muốn
  • Ẩn các field nhạy cảm nếu cần
  • Tái sử dụng ở nhiều endpoint
BƯỚC 4

Sử Dụng Resource Trong Controller

Cập nhật PostController để sử dụng PostResource:

<?php

namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use App\Models\Post;
use App\Http\Resources\PostResource;
use Illuminate\Http\Request;
use Illuminate\Http\Response;

class PostController extends Controller
{
    public function index()
    {
        $posts = Post::all();
        return response()->json([
            'success' => true,
            'data' => PostResource::collection($posts),
            'message' => 'Danh sách posts'
        ], Response::HTTP_OK);
    }

    public function show($id)
    {
        $post = Post::findOrFail($id);
        return response()->json([
            'success' => true,
            'data' => new PostResource($post),
            'message' => 'Chi tiết post'
        ], Response::HTTP_OK);
    }

    public function store(Request $request)
    {
        $validated = $request->validate([
            'title' => 'required|string|max:255',
            'content' => 'required|string'
        ]);
        
        $post = Post::create($validated);
        return response()->json([
            'success' => true,
            'data' => new PostResource($post),
            'message' => 'Tạo post thành công'
        ], Response::HTTP_CREATED);
    }
}
💡 Cách sử dụng:
  • new PostResource($post) cho single resource
  • PostResource::collection($posts) cho multiple resources

GỢI Ý

Troubleshooting - Xử Lý Lỗi

❌ Lỗi: 404 Not Found

Nguyên nhân: Routes không được định nghĩa hoặc URL sai
Giải pháp:
  • Kiểm tra lại routes/api.php
  • Đảm bảo controller đúng tên: Api/PostController
  • Restart Laravel server: php artisan serve

❌ Lỗi: Call to undefined method

Nguyên nhân: Quên import Model hoặc Response
Giải pháp: 
use App\Models\Post;
use Illuminate\Http\Response;

❌ Lỗi: Validation Error (422)

Nguyên nhân: Dữ liệu gửi lên không hợp lệ
Giải pháp: Kiểm tra Body JSON có khớp với validation rules hay không

❌ Lỗi: CORS Error

Nguyên nhân: Frontend gọi API từ domain khác
Giải pháp: Cấu hình CORS trong config/cors.php (sẽ học ở chương sau)
